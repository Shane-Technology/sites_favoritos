# Meus Sites Favoritos

Este projeto foi desenvolvido para a introdução ao **HTML5**, com o objetivo de criar uma página contendo alguns dos meus sites favoritos.

## Sobre o projeto

A página apresenta uma lista de sites que utilizo ou considero interessantes. Cada site possui:

- Nome do site
- Logotipo
- Link clicável através da imagem
- Endereço do site
- Uma breve descrição.

Também adicionei um link para o meu perfil do GitHub no título da página.

## Conceitos praticados

Durante o desenvolvimento, foram utilizados alguns dos principais elementos estudados na atividade:

- `<!DOCTYPE html>` para declarar HTML5;
- `<html>` para estruturar o documento;
- `<head>` e `<body>` para organizar a página;
- `<h1>` para títulos;
- `<p>` para parágrafos;
- `<a>` para criação de links;
- `href` para definir os endereços dos links;
- `target="_blank"` para abrir links em uma nova aba;
- `<img>` para inserir imagens;
- `src` para indicar o endereço das imagens;
- `alt` para adicionar uma descrição alternativa às imagens;
- `<figure>` e `<figcaption>` para organizar imagens e suas legendas;
- `<br>` para quebras de linha;
- `<!-- -->` Comentários HTML para fazer anotações no código.

## ⭐ Sites apresentados

A página apresenta os seguintes sites:

- Pinterest
- Spotify
- YouTube
- Notion
- Ellipsus

## Organização da página

Além do conteúdo básico solicitado na atividade, foram adicionados elementos visuais para deixar a página mais organizada e personalizada, como:

- Divisor decorativo;
- Separadores entre os sites;
- Imagens clicáveis;
- Comentários explicando algumas partes do código.

O objetivo foi praticar os elementos aprendidos em HTML e, ao mesmo tempo, criar uma página com uma aparência mais pessoal.
